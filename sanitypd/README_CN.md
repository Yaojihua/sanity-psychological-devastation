# Sanity: Psychological Devastation（精神损毁）

> ## ⚠️ ALPHA 测试版
> 这是 **alpha 测试版**：机制、数值、配置键与命令在版本之间仍可能变动，内容也可能失衡或存在缺陷。
> **安装前请先备份存档。** 本版是 **第二部分测试版**：包含思维链与记忆片段的剩余部分；
> Boss 阶段与结局尚未加入。
> 非常欢迎反馈与 bug 报告 —— 见 [反馈 bug](#反馈-bug)。

**为 Minecraft 带来"理智"系统 —— 在原版 Sanity 模组的基础上进行了新的机制、物品、生物、命令设计。**

理智是一个"点数制"的精神状态：**所有生物**都有理智。理智越低，你看到的东西、听到的声音，
以及最终朝你扑来的东西，都会变得不对劲。

---

## 简介

这是一个独立模组（`modid: sanitypd`）。它的机制源自开源项目
**Sanity: Descent Into Madness**（作者 [croissantnova](https://github.com/croissantnova/SanityDescentIntoMadness)，MIT 协议），
并在此基础上进行了新的机制、物品、生物与命令设计。**原作者的著作权与许可声明被完整保留** ——
见 [LICENSE](LICENSE) 与 [NOTICE](src/main/resources/META-INF/NOTICE-sanitypd.txt)。

| 项 | 版本 |
|---|---|
| Minecraft | 1.20 / 1.20.1 |
| Forge | 46+ |
| **GeckoLib** | Forge 46 用 **4.2** · Forge 47.1+ 用 **4.8.4**（**必装**，见下方说明） |
| Jade（玉） | 可选 —— 装了会在提示框里多一行理智数值 |
| JEI | 可选 —— 会为思维转录台提供一页配方页 |

> 真正原因是 Forge 版本太低。**Forge 46 用 GeckoLib 4.2；Forge 47.1+ 用 4.8.4。**

## 安装

1. 装好 Minecraft 1.20.1 的 Forge。
2. 把 **GeckoLib** 和**本模组**放进 `mods/` 文件夹。
3. 启动游戏即可。无需其它配置，首次运行会自动生成配置文件。

## 功能

### 理智系统
* **点数制**：玩家上限 **100**，其它生物上限 = 其最大生命值。
* **所有生物都有理智**，不只是玩家。
* 被动影响（光照、黑暗、天气、泡水、饥饿、附近怪物、宠物、音乐、脚下方块……）
  与主动来源（睡觉、繁殖、交易、钓鱼、剪羊毛、成就、进食、踩坏耕地……）。
* 理智由**精神伤害**削减：它**走的是理智这条独立通路**（先扣理智，**超出当前理智的部分才 1:1 转真实伤害**），**根本不经过原版的护甲结算** ⇒ **护甲 / 原版抗性 / 原版附魔都替不了你挡**；能减它的只有 **举盾格挡**、本模组的**精神抗性**（稳定剂与思维给的）与 ***精神庇护*** 附魔。

### 状态效果
| 效果 | 作用 |
|---|---|
| **混乱** | 低理智状态 |
| **狂躁** | 快速掉理智，本身就可能致死 |
| **狂躁免疫** | 免疫狂躁真实伤害；**最后 5 秒**会显示独立的到期警告 |
| **无视内在** | 内在生物不会攻击你，爬者也不会自爆；**最后 5 秒**同样显示到期警告 |
| **精神流失** | 持续的精神伤害 |
| **理智恢复** | 每秒回复 1 点理智，持续 25 秒；吃马卡龙获得 |

### 附魔
| 附魔 | 效果 |
|---|---|
| **精神庇护** | 每级 1 点减伤，四件护甲均可附，生存最高 IV 级，不与其它附魔互斥 |
| **精神剥夺** | 武器附魔 —— 命中造成精神伤害 |
| **精神流失** | 使目标获得精神流失效果 |

### 物品
* **暗影剑 / 暗影斧** —— 本模组的武器。长按右键**蓄力补耐久**，代价是消耗理智。
  副手拿盾时**盾牌优先**（不会进入蓄力）。
* **暗影武器精锻** —— 铁砧左槽放暗影武器、右槽放*内在团块*，即可精锻：
  **1 团块 = +1 级 = +1 精神伤害 = 1 经验等级**，上限 100 级，**不参与经验惩罚**，附魔与耐久全保留。
  **按住 Shift** 可一次吃掉铁砧里所有团块。
* **内在碎片 / 内在团块 / 内在核心** —— 由内在生物掉落的合成材料。
* **心境稳定剂 α / β / γ / δ** —— 各自改变理智并附带一段保护：α 立刻回复 35 点理智（15 秒冷却），
  β 180 秒内免疫狂躁后期精神崩溃造成的生命流失（300 秒冷却），γ 60 秒内内在生物不再主动攻击你（120 秒冷却），
  **δ 立刻降低 40 点理智**（5 秒冷却）—— 给“想主动压低理智”的玩法用。
* **花环** —— 可佩戴的花饰。
* **马卡龙** —— 八种颜色；吃一个会获得**理智恢复**与原版生命恢复。
* **三只内在生物的刷怪蛋** —— 与模组其它物品一起放在**专用创造模式物品栏**里。

### 内在生物
当理智低下时会出现三种敌对生物。**它们没有理智**、免疫混乱与狂躁。击杀它们会掉落经验与内在材料，并回复理智。

**⚠️ 精神伤害打到它们身上 ≠ 打到玩家身上**（两套转化规则完全不同，别混）：

| 被打的是谁 | 精神伤害会怎样 |
|---|---|
| **玩家 / 普通生物** | 先扣理智；**超出当前理智的那部分 1:1 转成真实伤害** |
| **内在生物** | **没有理智可扣** ⇒ 整份伤害 × 自身精神抗性系数 × **2.5** 全部转成真实伤害 |

例：**尖啸伏爬者**抗性 20 ⇒ 系数 0.8 ⇒ 挨 **100 点精神伤害 = 200 点真伤**；
抗性 100 则表示完全免疫（转不出真伤）。

| 生物 | 特点 |
|---|---|
| **腐朽跟踪者** | 精神抗性 10 · 高大的无声追击者 |
| **惊骇潜行者** | 精神抗性 15 |
| **尖啸伏爬者** | 精神抗性 20 · 点燃引信、膨胀、自爆；爆炸造成**大量精神伤害** |

**尖啸伏爬者**会主动猎杀理智低于 **20%** 的玩家：它会**绕开障碍**（A\* 寻路）、**跨台阶与跳跃**、
近身自爆。它的眼睛在黑暗中会发光。

**它有两条理智闸门**，所以"已经恢复的玩家"不会再被它追着惩罚：

| 你的理智 | 爬者能做什么 |
|---|---|
| **≥75%** | 什么都不行 —— **完全不能追踪你**：拒绝把你设为目标，已经在追的会**立刻脱战** |
| **50% ~ 75%** | 可以追、可以自爆，但爆炸**不破坏任何方块**（伤害不变） |
| **<50%** | 正常行为：追、自爆、**方块照碎**（和苦力怕同规格） |

理智正常的玩家**看不见**内在生物，但它们在服务端依然存在，并照常计入你的被动掉理智；
不过**被它们锁定的玩家无论如何都能看见它们**。

**⚠️ 爬者为什么会致死**：它的爆炸造成的是**大量精神伤害**，而不是"只掉理智"。
精神伤害会削减理智，而**超出你当前理智的那部分会 1:1 转化为真实伤害**
（真实伤害无视护甲、附魔、盾牌与状态效果）。所以挨一发自爆时：**理智充足就只是掉理智，理智偏低就直接掉血甚至死亡**。
（精神庇护与举盾能减少"扣理智"那一段，但**溢出真伤无法被减伤**。）

**⚠️ 爬者不会伤到内在生物**：自爆结算会按 `sanitypd:inner_entities` 标签**跳过**所有内在生物 ——
它们既不吃精神伤害，也不吃溢出真伤。所以"两只内在生物站一起，一只自爆"**不会**炸死另一只。


### 思维链

* **精神控制仪**打开你自己的**思维链**：**十八格、两行九列** —— 一行**世界观**、一行**方法论**。
  **幻视**类思维两行都能放。
* 放进格子里的是**思维**，共六种计数类型（镇静、疯狂、奴役、混沌限制、忍耐、**幻视**）；
  少数思维同时属于两种类型，两边的计数都算。目前共 **24 枚**。
* 同一类型的思维越多，单枚效果越深；tooltip 显示当前效果，按住 SHIFT 查看完整档位表。
* **思维定式**在同类型数量达标时激活，**思维趋势**面板显示当前生效的思维定式。

### 思维容器与思维转录台

* **思维容器**是思维的载体形态。不分类型的那种**思维容器**用三块玻璃加一个**内在团块**合成
  （`g c g` / `. g .`）；四种类型变种 —— **思维容器：镇静**、**思维容器：疯狂**、**思维容器：奴役**、
  **思维容器：忍耐** —— 无法合成，只能在转录台上做出。
* **思维转录台**里放**三枚同类型思维**、不分类型的思维容器与一个**内在核心**，即可产出该类型的变种容器，
  花费 **2 级经验**。
* 原料格里改放**一枚带档位的思维**，配合该类型的变种容器与内在核心，就能拿回**同一枚已被强化**的
  思维（描述栏多出一行金色「该思想已强化」），花费 **3 级经验**。已强化的思维不能再放回去。
* **幻视**与**混沌限制**没有变种容器，因此这两类思维无法转录。
* 窗口会**先显示花费**，取出才结算；装了 **JEI** 的话同一套配方可以在配方页里翻看。

### 失落的记忆片段

* 一共**九枚片段**。其中**四枚**是主线（放在本模组的创造栏里）；另外五枚要在游戏里被交到你手上，
  至于怎么拿到，留给你自己找。
* 长按右键以**拉弓姿势**蓄力：**HUD 会隐藏，但你的手与手持物仍然可见**。
* 一秒后起蓄力音；音效一结束**屏幕转黑**，开始**一盘磁带**：逐句念出该片段的剧本，底部噪声带全程都在，
  每句由一次磁带弹出音引出，最后一句之后**渐白**收尾。
* 每枚片段**首次播放不可跳过**；看过一次后任意键退出。单人模式下会**暂停游戏**；联机时你受**创造式免伤**保护。
* 每枚片段都带**中文与英文两份剧本**，按客户端语言选择。
* 看满**九枚中的八枚**后，**七盘磁带**会变样：原先被遮住的字变成可读文字，并且你会被通知一次。

* **灵感来源**：磁带这一段的表现形式参考了 **Poppy Playtime** 的死亡界面。**未使用该游戏的任何素材** —— 效果完全由本模组自己的代码与贴图实现。

### 暗影火药与暗影TNT

* **暗影火药**只由**尖啸伏爬者**掉落 —— 一次一到两个，且必须由玩家击杀。
* **暗影TNT**用它按原版 TNT 的摆法合成（沙或红沙皆可）。爆炸造成**无视距离衰减的精神伤害**，
  方块照碎（和 TNT 一样），击杀时的死亡消息会**点名是谁点的引信**，若是自己点的则另有措辞。

## 陪跑工具：SanityPD 思维探针（Mind Probe）

本项目还附带一个**独立、可选**的诊断模组 `sanityprobe`。**玩法完全不需要它**，它也不改变任何游戏内容；
它的意义是让"只有在真实客户端上才看得到的行为"变得可验证 —— 专用服务器无法证明渲染、HUD 与动画相关的问题。

**怎么装**：把 `sanityprobe-mc1.20-2.40.0.jar` 与主模组一起丢进 `mods/` 即可，无需任何设置。
用完直接删掉它，没有任何东西依赖它。

**东西在哪看**：

| 位置 | 内容 |
|---|---|
| `<实例>/logs/sanityprobe.log` | 一行一件事，带 `[标签]`，例如 `[SHIELD-26-C]`、`[CHASE-27]`、`[SELF-INJURY-75]`、`[BLOOD-78]` |
| `logs/latest.log` | 同样内容镜像成 `[PROBE] ...` 行 |
| 屏幕左上角叠加层 | 实时读数；**F4** 隐藏/显示（可在"控制"里改键） |

**命令**（客户端命令，不需要管理员权限）：

| 命令 | 作用 |
|---|---|
| `/sanityprobe on` | 开启日志 |
| `/sanityprobe off` | 关闭日志（叠加层仍在） |
| `/sanityprobe mark <文本>` | 往日志里插一条 `MARK` 行，用来给你刚做的事打时间戳 |
| `/sanityprobe` | 打印用法 |

**它观察什么** —— 一个机制一组，各自写自己的带标签行；这一版装了哪些组，看探针启动横幅上的列表。
日志里会出现的标签包括：

* `[WALK-S]` `[WALK-C]` `[FLOAT-C]` —— 爬者到底有没有在走：走路动画判定、着地状态、浮空表现
* `[AI-27]` `[AI-27-TL]` `[AI-27-NEWPATH]` `[AI-27-CMD]` `[CHASE-27]` —— 爬者的目标、正在跑的 goal、
  实际算出的 A\* 路径、以及真正下发的移动指令
* `[CRAWLER-29]` —— 决定爬者"能做什么"的两条理智闸门
* `[SOUND-C]` —— 模组播的每个声音、距离、以及资源能否解析到
* `[TAPE-49]` —— 记忆片段磁带：序列状态、底层嘶声的句柄、以及"非磁带自身"的声音是否真的被静音
* `[TAPE-GATE-53]` —— 磁带的准入闸门与隐藏片段的额度
* `[THOUGHT]` `[THOUGHT41-29]` `[THOUGHT50]` `[THOUGHT50-C]` `[THOUGHT-ATTR]` —— 思维本身：注册 id、
  计数类型、机制读取的常量、tooltip 真正打出来的句子，以及思维与思维定式加在你身上的属性修饰符
* `[BLOCK-61]` —— 思维转录台（从客户端侧检查）
* `[VISION-58]` —— 幻视那一批
* `[DEPERSON-44]` —— 人格解体思维及其理智回复上限
* `[STAB-C]` —— 心境稳定剂
* `[SNEAK-HUD]` —— 潜行时画在理智条上方的那行数值
* `[SHIELD-26-C]` —— 暗影武器与副手盾之间的右键优先级
* `[ENCH-26-C]` —— 精神庇护附魔
* `[REFINE-26-C]` —— 铁砧暗影精锻的产物
* `[HINT-TIER]` `[HINT-24]` `[HINTWIN-28]` —— 内心独白各池、池的条数、以及警告窗口的规则
* `[TYPEHINT-43]` —— 按类型分的内心声音池
* `[VOICE-32]` —— 额外的那一道内心声音与它触发的声音
* `[SELF-INJURY-75]` `[HINT-POOL-76]` —— 自残在客户端侧的时间线，以及自残专属标语池
* `[BLOOD-78]` —— 留在地上的血渍贴花
* `[SHADOW-TNT-63]` —— 暗影TNT
* `[SCREAM-52]` —— 低理智尖叫
* `[MACARON-60]` `[SELF-59]` `[VOID-64]` `[VESSEL-65]` —— 那四枚"在游戏里被交到你手上"的片段
* `[UNBOUND-66]` —— 看满足够片段后变为可读的那些磁带行
* `[EGG-25]` `[EGG-25-C]` `[EGG-26-C]` `[EGG-33]` —— 刷怪蛋与"不许直呼那个名字"彩蛋
* `[DEATH]` `[IMMUNE-24]` `[DEATH-FLAVOUR]` —— 死亡消息与伤害链路
* `[IMPACT-24]` `[MELEE-24]` `[CMD-24]` `[LANG-24]` —— 精神抗性、内在生物伤害加成、命令与语言键
* `[P26]` —— 一次跑完的汇总检查清单（把客户端各组一起写进日志）
* `[SPLASH-26]` —— 标题屏标语
* `[HUD-27]` —— 叠加层的版式引擎，以及它内部的任何绘制失败
* `[SELFTEST]` `[SYS]` `[SYSMSG]` —— 探针自身的启动自检、系统消息、以及服务端所有系统广播

**反馈 bug**：把 `logs/sanityprobe.log` 附上即可 —— 这一个文件就够看出发生了什么，屏幕叠加层只是方便你肉眼对照。

## 命令

根命令是 `/sanity`。下面**除两处外都需要管理员权限**；这两处任何玩家都能用，所以在关闭作弊的极限
模式里依然可用：对自己用的 `/sanity selfinjury`，以及用来写自己内心台词的 `/sanity hint ...` 标语池编辑。

| 命令 | 用途 |
|---|---|
| `/sanity get [目标]` | 读取理智 |
| `/sanity set <目标> <数值>` | 设置理智 |
| `/sanity add <目标> <数值>` | 增减理智 |
| `/sanity state <目标> <状态>` | 强制状态 |
| `/sanity psychic <目标> <数值>` | 造成精神伤害 |
| `/sanity truedamage <目标> <数值>` | 造成真实伤害 |
| `/sanity resist set\|add\|subtract\|clear\|get` | 设置实体的精神抗性 |
| `/sanity innerspawn on\|off\|status` | 仅禁止内在生物生成 |
| `/sanity nospawn on\|off\|status` | 禁止自然刷怪 |
| `/sanity hint <档位> add\|remove\|list\|clear\|show` | 管理内心独白标语池（温和 / 严重 / 深层 / **免疫到期**）。<br>**档位怎么用**：理智 ≤25% 时**只**从「严重」池抽取（不会再用深层）；「深层」只在**躁狂开始扣血前 5 秒**随机抽一条说出；持有**狂躁免疫**期间只从「严重」池抽取，免疫**到期前 5 秒**改为显示「**免疫到期**」池（内置 3 条，可用 `expiry` 档位增删） |
| `/sanity config reload` | 重载配置 |

### 多人游戏注意：提交带「那个词」的标语时

自定义标语里如果提到某个特定的词（字母之间夹标点或空格也算），命令会被拒绝。之后发生什么，取决
于你在哪一侧：

* **你自己的游戏会立刻关闭** —— 单机与多人游戏都一样，且**只影响亲自打这条命令的人**。
* **专用服务器绝不会崩。** 服务端有它自己的一半职责：命令被**无任何提示地**吞掉，同时打这条命令的
  玩家当场受到致命伤害。服务端进程本身毫发无伤，因此这条路径不可能造成存档数据丢失。
* **命令方块与服务端控制台永远不会触发它。** 命令背后没有玩家时什么都不会发生 —— 既不崩也不掉血，
  只有玩家自己亲手输入才有效。
