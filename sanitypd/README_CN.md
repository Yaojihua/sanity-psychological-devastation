# Sanity: Psychological Devastation（精神损毁）

> ## ⚠️ ALPHA 测试版
> 这是 **alpha 测试版**：机制、数值、配置键与命令在版本之间仍可能变动，内容也可能失衡或存在缺陷。
> **安装前请先备份存档。** 非常欢迎反馈与 bug 报告 —— 见 [反馈 bug](#反馈-bug)。

**为 Minecraft 带来"理智"系统 —— 在原版 Sanity 模组的基础上进行了新的机制、物品、生物、命令设计。**

理智是一个"点数制"的精神状态：**所有生物**都有理智。理智越低，你看到的东西、听到的声音，
以及最终朝你扑来的东西，都会变得不对劲。

---

## 简介

这是一个独立模组（`modid: sanitypd`）。它的机制源自开源项目
**Sanity: Descent Into Madness**（作者 [croissantnova](https://github.com/croissantnova/SanityDescentIntoMadness)，MIT 协议），
并在此基础上进行了新的机制、物品、生物与命令设计。**原作者的著作权与许可声明被完整保留** ——
见 [LICENSE](LICENSE) 与 [NOTICE](src/main/resources/META-INF/NOTICE-sanitypd.txt)。

## 前置要求

| 项 | 版本 |
|---|---|
| Minecraft | 1.20 / 1.20.1 |
| Forge | 46+ |
| **GeckoLib** | Forge 46 用 **4.2** · Forge 47.1+ 用 **4.8.4**（**必装**，见下方说明） |
| Jade（玉） | 可选 —— 装了会在提示框里多一行理智数值 |

> **GeckoLib 版本必须与 Forge 版本搭配。** GeckoLib 4.2.1~4.8.4 自己声明 `loaderVersion="[47,)"`，
> 在 Forge 46 上无法加载。搭配错了游戏会报"**缺少 geckolib 前置**"—— **那个报错是误导**，
> 真正原因是 Forge 版本太低。**Forge 46 用 GeckoLib 4.2；Forge 47.1+ 用 4.8.4。**

## 安装

1. 装好 Minecraft 1.20.1 的 Forge。
2. 把 **GeckoLib** 和**本模组**放进 `mods/` 文件夹。
3. 启动游戏即可。无需其它配置，首次运行会自动生成配置文件。

## 功能

### 理智系统
* **点数制**：玩家上限 **100**，其它生物上限 = 其最大生命值。
* **所有生物都有理智**，不只是玩家。
* 被动影响（光照、黑暗、天气、泡水、饥饿、附近怪物、宠物、音乐、脚下方块……）
  与主动来源（睡觉、繁殖、交易、钓鱼、剪羊毛、成就、进食、踩坏耕地……）。
* 理智由**精神伤害**削减：**精神伤害不吃护甲**（设计如此），只有*精神庇护*附魔或**举盾格挡**能减伤。

### 状态效果
| 效果 | 作用 |
|---|---|
| **混乱** | 低理智状态 |
| **躁狂** | 快速掉理智，本身就可能致死 |
| **狂躁免疫** | 免疫躁狂真实伤害；**最后 5 秒**会显示独立的到期警告 |
| **无视内在** | 内在生物不会攻击你，爬者也不会自爆；**最后 5 秒**同样显示到期警告 |
| **精神流失** | 持续的精神伤害 |

### 附魔
| 附魔 | 效果 |
|---|---|
| **精神庇护** | 每级 1 点减伤，四件护甲均可附，生存最高 IV 级，不与其它附魔互斥 |
| **精神剥夺** | 武器附魔 —— 命中造成精神伤害 |
| **精神流失** | 使目标获得精神流失效果 |

### 物品
* **暗影剑 / 暗影斧** —— 本模组的武器。长按右键**蓄力补耐久**，代价是消耗理智。
  副手拿盾时**盾牌优先**（不会进入蓄力）。
* **暗影武器精锻** —— 铁砧左槽放暗影武器、右槽放*内在团块*，即可精锻：
  **1 团块 = +1 级 = +1 精神伤害 = 1 经验等级**，上限 100 级，**不参与经验惩罚**，附魔与耐久全保留。
  **按住 Shift** 可一次吃掉铁砧里所有团块。
* **内在碎片 / 内在团块 / 内在核心** —— 由内在生物掉落的合成材料。
* **心境稳定剂 α / β / γ** —— 恢复理智并给予一段保护：**β** 免疫躁狂真实伤害，**γ** 让内在生物无视你（各自有冷却）。
* **花环** —— 可佩戴的花饰。
* **三只内在生物的刷怪蛋** —— 与模组其它物品一起放在**专用创造模式物品栏**里。

### 内在生物
当理智低下时会出现三种敌对生物。**它们没有理智**、免疫混乱与躁狂。击杀它们会掉落经验与内在材料，并回复理智。

**⚠️ 精神伤害打到它们身上 ≠ 打到玩家身上**（两套转化规则完全不同，别混）：

| 被打的是谁 | 精神伤害会怎样 |
|---|---|
| **玩家 / 普通生物** | 先扣理智；**超出当前理智的那部分 1:1 转成真实伤害** |
| **内在生物** | **没有理智可扣** ⇒ 整份伤害 × 自身精神抗性系数 × **2.5** 全部转成真实伤害 |

例：**尖啸伏爬者**抗性 20 ⇒ 系数 0.8 ⇒ 挨 **100 点精神伤害 = 200 点真伤**；
抗性 100 则表示完全免疫（转不出真伤）。

| 生物 | 特点 |
|---|---|
| **腐朽跟踪者** | 精神抗性 10 · 高大的无声追击者 |
| **惊骇潜行者** | 精神抗性 15 |
| **尖啸伏爬者** | 精神抗性 20 · 点燃引信、膨胀、自爆；爆炸造成**大量精神伤害** |

**尖啸伏爬者**会主动猎杀理智低于 **20%** 的玩家：它会**绕开障碍**（A\* 寻路）、**跨台阶与跳跃**、
近身自爆。它的眼睛在黑暗中会发光。

**它有两条理智闸门**，所以"已经恢复的玩家"不会再被它追着惩罚：

| 你的理智 | 爬者能做什么 |
|---|---|
| **≥75%** | 什么都不行 —— **完全不能追踪你**：拒绝把你设为目标，已经在追的会**立刻脱战** |
| **50% ~ 75%** | 可以追、可以自爆，但爆炸**不破坏任何方块**（伤害不变） |
| **<50%** | 正常行为：追、自爆、**方块照碎**（和苦力怕同规格） |

理智正常的玩家**看不见**内在生物，但它们在服务端依然存在，并照常计入你的被动掉理智；
不过**被它们锁定的玩家无论如何都能看见它们**。

**⚠️ 爬者为什么会致死**：它的爆炸造成的是**大量精神伤害**，而不是"只掉理智"。
精神伤害会削减理智，而**超出你当前理智的那部分会 1:1 转化为真实伤害**
（真实伤害无视护甲、附魔、盾牌与状态效果）。所以挨一发自爆时：**理智充足就只是掉理智，理智偏低就直接掉血甚至死亡**。
（精神庇护与举盾能减少"扣理智"那一段，但**溢出真伤无法被减伤**。）

**⚠️ 爬者不会伤到内在生物**：自爆结算会按 `sanitypd:inner_entities` 标签**跳过**所有内在生物 ——
它们既不吃精神伤害，也不吃溢出真伤。所以"两只内在生物站一起，一只自爆"**不会**炸死另一只。

## 陪跑工具：SanityPD 思维探针（Mind Probe）

本项目还附带一个**独立、可选**的诊断模组 `sanityprobe`。**玩法完全不需要它**，它也不改变任何游戏内容；
它的意义是让"只有在真实客户端上才看得到的行为"变得可验证 —— 专用服务器无法证明渲染、HUD 与动画相关的问题。

**怎么装**：把 `sanityprobe-mc1.20-2.7.0.jar` 与主模组一起丢进 `mods/` 即可，无需任何设置。
用完直接删掉它，没有任何东西依赖它。

**东西在哪看**：

| 位置 | 内容 |
|---|---|
| `<实例>/logs/sanityprobe.log` | 一行一件事，带 `[标签]`，例如 `[SHIELD-26-C]`、`[CHASE-27]`、`[HUD-27]` |
| `logs/latest.log` | 同样内容镜像成 `[PROBE] ...` 行 |
| 屏幕左上角叠加层 | 实时读数；**F4** 隐藏/显示（可在"控制"里改键） |

**命令**（客户端命令，不需要管理员权限）：

| 命令 | 作用 |
|---|---|
| `/sanityprobe on` | 开启日志 |
| `/sanityprobe off` | 关闭日志（叠加层仍在） |
| `/sanityprobe mark <文本>` | 往日志里插一条 `MARK` 行，用来给你刚做的事打时间戳 |
| `/sanityprobe` | 打印用法 |

**它观察什么**（一个机制一组）：

* 走路 / 浮空 —— 爬者的走路动画判定与着地状态
* 音效 —— 模组播的每个声音、距离、以及资源能否解析到
* 稳定剂 —— 物品冷却与效果起止
* 潜行 HUD —— 潜行时的理智读数与其翻译键
* 盾牌 —— 副手盾是否抢到了右键（而不是武器进入蓄力）
* 彩蛋 —— "不许直呼那个名字"有没有按预期触发
* 附魔 / 精锻 —— 精神庇护的数值、铁砧精锻的产物
* 标语 —— 标题屏标语池
* AI / 追踪 —— 爬者的目标、正在跑的 goal、A\* 路径与移动指令
* HUD 版式 —— 叠加层自身行数（一旦哪行重叠立刻能看出来）

**反馈 bug**：把 `logs/sanityprobe.log` 附上即可 —— 这一个文件就够看出发生了什么，屏幕叠加层只是方便你肉眼对照。

## 开发路线

本模组**正在持续开发中** —— 现在这一版是**骨架**，不是完成品。

* **装备系统** —— 强化或限制心智的装备：思维强化类物品，以及"自限制"类装备（你自己给自己上约束，
  从而改变理智的运作方式）。
* **最终战斗** —— 整套理智系统最终要指向的终局内容。
* 随着上面两套系统落地，还会补更多内在生物、物品与理智来源。

这也正是 alpha 标注的含义：**骨架可玩，长在上面的内容还没到**。
## 命令

所有命令都需要管理员权限，根命令是 `/sanity`。

| 命令 | 用途 |
|---|---|
| `/sanity get [目标]` | 读取理智 |
| `/sanity set <目标> <数值>` | 设置理智 |
| `/sanity add <目标> <数值>` | 增减理智 |
| `/sanity state <目标> <状态>` | 强制状态 |
| `/sanity psychic <目标> <数值>` | 造成精神伤害 |
| `/sanity truedamage <目标> <数值>` | 造成真实伤害 |
| `/sanity resist set\|add\|subtract\|clear\|get` | 设置实体的精神抗性 |
| `/sanity innerspawn on\|off\|status` | 仅禁止内在生物生成 |
| `/sanity nospawn on\|off\|status` | 禁止自然刷怪 |
| `/sanity hint <档位> add\|remove\|list\|clear\|show` | 管理内心独白标语池（温和 / 严重 / 深层 / **免疫到期**）。<br>**档位怎么用**：理智 ≤25% 时**只**从「严重」池抽取（不会再用深层）；「深层」只在**躁狂开始扣血前 5 秒**随机抽一条说出；持有**狂躁免疫**期间只从「严重」池抽取，免疫**到期前 5 秒**改为显示「**免疫到期**」池（内置 3 条，可用 `expiry` 档位增删） |
| `/sanity config reload` | 重载配置 |

## 配置

首次运行会生成**每项都有注释**的配置文件 `config/sanitypd/default.toml`：
被动与主动理智来源、物品与方块列表、多人游戏与客户端选项
（理智指示器、内心独白、血丝遮罩、后处理特效、音效）。
